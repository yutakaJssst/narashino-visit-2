# AIと作る学校紹介サイト（日本大学習志野高等学校）

日本大学理工学部 応用情報工学科の模擬講義（2026-09-08 学部見学会）で、AIを使ったWebサイト制作をその場で見せるためのサイトです。
ビルド手順は不要で、`index.html` をブラウザで開くだけで動きます。

模擬講義は2回あり、リポジトリを分けています。どちらも同じベースラインから始めます。

| 回 | 時間 | 人数 | リポジトリ | 公開URL |
| --- | --- | --- | --- | --- |
| 1回目 | 14:25〜14:45 | 20名 | `narashino-visit-1` | https://yutakajssst.github.io/narashino-visit-1/ |
| 2回目 | 15:00〜15:20 | 40名 | `narashino-visit-2` | https://yutakajssst.github.io/narashino-visit-2/ |

## ファイル構成

- `index.html`: ページの器。見出しも本文も空で、`script.js` が流し込みます
- `styles.css`: 明朝＋ゴシック＋等幅の編集的なデザイン
- `script.js`: 冒頭の `siteData` にすべての内容。続けて描画、SVG生成、ミニゲームのエンジン
- `tools/check-stages.mjs`: ミニゲームのステージが本当にクリアできるかを確かめるチェッカー
- `assets/narashino-visit-2-qr.png`: 公開URLのQRコード
- `notes/nichidai-narashino-research.md`: 公式サイトから集めた学校情報と出典
- `notes/session-plan-20260908.md`: 20分の進行案、聞き取り台本、プロンプト、チェックリスト

## ページの構成

ヒーロー（校訓を3行で）→ ニューステロップ → 数字 → 01 魅力 → 自主創造 → 02 学び（3コース）→ 03 生徒の声 → 04 行事 → 05 部活動 → 06 キャンパスと通学路 → 07 ミニゲーム。

「魅力」と「生徒の声」は当日の生徒の声で置き換える前提です。生徒の声は点線の枠で「募集中」と表示されています。

## ミニゲーム「日習クエスト」

船橋日大前駅から校舎の陸橋まで、3ステージの横スクロールアクションです。歩く・飛ぶ敵、すり抜け床、動く床、ジャンプ台、トゲ、中間地点があり、敵は上から踏むと倒せます。キーボード（← → とスペース）とスマホのボタンの両方で遊べます。

ステージは `siteData.game.stages[].map` に文字で書いた地図です。`#` を1つ足せば足場が増え、`E` を書けば敵が現れます。記号の意味と設計ルールは `CLAUDE.md` にまとめてあります。

ステージを書き換えたら、次を実行してクリアできるか確かめます。

```bash
node tools/check-stages.mjs
```

## 当日の使い方

1. 生徒に学校のいいところ、売店の人気、テーマカラー、ゲームの敵の名前を挙手投票で聞きます。
2. Claude Code に `notes/session-plan-20260908.md` のプロンプト1を、聞いた内容で埋めて渡します。
3. ブラウザを再読み込みして、サイトが変わる様子を見せます。
4. 生徒の指摘をもとにプロンプト2で修正し、ゲームも変えます。
5. `git push` して GitHub Pages に公開し、QRを見せます。

内容の変更は `script.js` 冒頭の `siteData` だけで済みます。AIが止まったときは手で書き換えても動きます。

## 写真について

公式サイトの写真は利用許諾が未確認のため載せていません。当日撮った写真を生徒の了解のもとで `assets/photos/` に置き、AIに写真セクションを追加させることはできます。`styles.css` に `photo-grid` `photo-card` のスタイルを用意してあります。

## 外部リソース

Google Fonts から3書体（Shippori Mincho B1 / Zen Kaku Gothic New / DM Mono）を読み込みます。オフラインでもフォールバックの明朝・ゴシックで表示されるため、デモは成立します。

## GitHub Pagesで公開

1. GitHubでこのリポジトリを開きます。
2. `Settings` から `Pages` を開きます。
3. `Build and deployment` で `Deploy from a branch` を選びます。
4. Branchを `main`、Folderを `/ (root)` にして保存します。

反映には1〜2分かかります。前日にベースラインを公開しておくと、当日はURLが必ず開きます。
