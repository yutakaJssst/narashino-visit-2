# AIと作る学校紹介サイト（明和県央高等学校）

日本大学理工学部 応用情報工学科のミニ講義（2026-10-06 見学会）で、AIを使ったWebサイト制作をその場で見せるためのサイトです。ビルドは不要で、`index.html` をブラウザで開くだけで動きます。

このリポジトリは **A班・2回目（10名、14:00〜14:30）** 用です。もう一方の回は `../narashino-visit-1` を使います。リポジトリ名と公開URLは既存のQRコードを維持するため、そのままです。

| --- | --- | --- | --- | --- | --- |
| 1回目 | B班 | 13:00〜13:30 | 9名 | `narashino-visit-1` | https://yutakajssst.github.io/narashino-visit-1/ |
| 2回目 | A班 | 14:00〜14:30 | 10名 | `narashino-visit-2` | https://yutakajssst.github.io/narashino-visit-2/ |

## ファイル構成

- `index.html`: ページの器。見出しと本文は `script.js` が流し込みます
- `styles.css`: 明朝、ゴシック、等幅を使ったデザイン
- `script.js`: 冒頭の `siteData` に文面、色、ゲームの内容を集約
- `tools/check-stages.mjs`: ゲームの各ステージがクリアできるか確認
- `assets/narashino-visit-2-qr.png`: この回の公開URLのQRコード
- `notes/meiwakenoh-research.md`: 明和県央高校の公式情報と出典、添付日程の要点
- `notes/session-plan-20261006.md`: 30分の進行案、聞き取り、当日用プロンプト
- `slides/meiwakenoh20261006.pptx`: 今回の発表スライド17枚

## ページの構成

建学の精神「進取」から始まり、数字、学校の魅力、4コース、生徒の声、行事、29の部活動、施設とアクセス、ミニゲームへ続きます。

校名、コース、施設などは公式情報を入れています。「生徒の声」は3枠とも点線の「募集中」です。当日に聞いた言葉を入れ、`placeholder: true` を外すと実線になります。

## ミニゲーム「明和県央クエスト」

群馬総社駅から学校へ向かい、広い校地を進んでC-HALLを目指す3ステージの横スクロールアクションです。キーボード（← → とスペース）とスマホのボタンで遊べます。

ステージは `siteData.game.stages[].map` の文字列です。地図を変えたら、必ず次を実行してください。

```bash
node tools/check-stages.mjs
```

## 当日の使い方

1. 生徒に学校のいいところ、給食、学校らしい色、ゲーム案を聞きます。
2. `notes/session-plan-20261006.md` のプロンプト1へ、聞いた言葉を入れてAIに渡します。
3. ブラウザを再読み込みし、生徒と一緒に内容を確認します。
4. 指摘とゲーム案をプロンプト2で反映します。
5. GitHub Pagesへ公開し、この回のQRコードを見せます。

内容の変更は `script.js` 冒頭の `siteData` だけで行います。その下の描画処理、SVG生成、ゲームエンジンは変更しません。

## 写真について

前回校の生徒写真は、今回の参加者の写真として使いません。ベースラインには教員の過去の講義写真を「過去の写真」と明記して表示しています。当日に撮影許可を得た写真があれば、`siteData` の写真パスと説明だけを差し替えます。

## 確認

```bash
node --check script.js
node tools/check-stages.mjs
```

投影前に `index.html` をPCとスマホ幅で確認し、スライドの最終ページにこの回のQRコードが出ていることも確認します。

## GitHub Pages

公開設定は `main` ブランチの `/ (root)` です。反映に時間がかかることがあるため、当日の開始前にベースラインを公開しておきます。
