## 各ページの意図

- **3ページ（キャンパス地図）**: 船橋日大前駅・14号館（この教室）・2号館（応用情報工学科）・日大習志野高校の4点に注記。同じキャンパスの中にあることを一目で見せます。
- **5ページと13ページ（6年前との比較）**: 動画はCSTコースの皆さんが6年前に作ったものです。当時はUnityの使い方を覚えるところから半年かかりました。13ページで、6年前・2022年11月のChatGPT公開・今日の20分を並べ、「半年かかったことが、いまは数十分」につなげます。この学科の先生自身が見てきた変化なので、実感を持って話せる材料です。
- **9ページ（AIへの頼み方）**: プロンプトの例です。当日は生徒から聞いた言葉で中身が変わります。ゲームへの希望も同じプロンプトに入れます。3つのコツのうち「出てきたものを見て、言い直す」は、10ページ・11ページの往復の話につながります。「聞いた言葉をそのまま渡す」「どこを変えるか名指しする」「変えないでほしい所も言う」の3点が、AIとの対話の作法です。
- **11ページ（対話の記録）**: このサイトとスライドを作ったときのGit履歴から、実際の時刻と指示を並べたものです。うまくいかないと言い続けたのが人間だった、という話に使います。
- **15ページ（AIも間違えます）**: 実際に起きたバグのbefore/afterです。ジャンプ台の勢いが消えて足場に届かなかった不具合を、本物のゲーム画面と実際の軌跡で示しています。

## 作り直すとき

`build_deck.py` が生成スクリプトです。`images/` の素材を使います。

```bash
python3 build_deck.py images nichinara20260908.pptx 2
```

最後の引数が「何回目か」です。1 なら narashino-visit-1 のQR、2 なら narashino-visit-2 のQRが入ります。

文言を少し直すだけなら PowerPoint で直接編集する方が早いです。
