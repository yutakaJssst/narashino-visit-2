## 2回実施するときの注意

- **17ページは1回目用、18ページは2回目用**です。URLが違います。取り違えると生徒が別のグループのサイトを開きます。
- 使わない方のページは、当日「スライドを非表示にする」で隠してください。
- 2回目の最後に1回目の成果を見せるなら、スライドを1枚足してください。

## 作り直すとき

`build_deck.py` が生成スクリプトです。`images/` の画像を使います。

```bash
python3 build_deck.py images nichinara20260908.pptx
```

文言を少し直すだけなら PowerPoint で直接編集する方が早いです。
スクリプトは、大きく作り直したいときや来年別の高校で使い回すときのためのものです。
